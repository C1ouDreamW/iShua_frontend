## 高优先级

### UX-001 错题筛选为空时无法切回全部题库

- 状态：**待修复**
- 位置：`src/pages/WrongQuestionsPage.tsx:154`
- 现象：筛选器只在 `records.length > 0` 时渲染。选择一个没有错题的题库后，筛选器随列表一起消失，用户无法切回“全部题库”。
- 建议：筛选器应独立于列表状态常驻；空状态文案应说明当前筛选无结果，并提供“清除筛选”。

### UX-002 删除分页最后一条数据后卡在假空页

- 状态：**待修复**
- 位置：`src/pages/WrongQuestionsPage.tsx:120`、`src/pages/BankDetailPage.tsx:331`
- 现象：错题本和试题管理删除当前页最后一项后，会继续请求原页码；返回空列表后分页器被隐藏，用户无法回到上一页。
- 建议：删除成功后根据最新总数校正页码，或在空页时自动回退一页并重新加载。

### UX-003 删除选项后正确答案字母不会重排

- 状态：**待修复**
- 位置：`src/pages/QuestionFormPage.tsx:175`
- 现象：例如正确答案为 C，删除 B 后，原 C 已变为 B，但答案仍保存为 C，可能造成错误判分。
- 建议：删除选项时根据新索引重建所有答案字母，并补充单元测试。

### UX-004 提交时过滤空白选项会导致答案错位

- 状态：**待修复**
- 位置：`src/lib/questionForm.ts:121`
- 现象：空白选项会在生成 payload 时被过滤，但答案字母不会同步调整。校验也没有确认答案是否指向非空选项。
- 建议：不要在提交阶段静默压缩选项；应在表单层阻止空洞选项，或同时重排答案。

### UX-005 自动下一题可能连续跳过两题

- 状态：**待修复**
- 位置：`src/hooks/usePracticeSession.ts:215`、`src/hooks/useWrongPracticeSession.ts:182`、`src/pages/GuestPracticePage.tsx:217`
- 现象：答对后创建 600ms 定时器。用户在定时器触发前手动切题或关闭“自动下一题”，旧定时器不会取消，随后还会继续前进一次。
- 建议：封装统一的切题方法，在手动切题、关闭自动跳转、完成练习和重试时清理定时器。

### UX-006 题库新建/编辑抽屉会无提示丢失输入

- 状态：**待修复**
- 位置：`src/components/bank/BankNodeFormDrawer.tsx:141`、`src/components/bank/BankFormDrawer.tsx:117`
- 现象：用户填写名称或描述后，点击遮罩或取消会直接关闭抽屉，没有未保存确认。
- 建议：增加 dirty 状态和离开确认，行为与试题编辑页保持一致。

### UX-007 移动端注册表单被权限表大幅推后

- 状态：**已修复**
- 位置：`src/pages/RegisterPage.tsx:55`、`src/components/auth/RoleFeatureCompare.tsx:46`
- 现象：375px 宽浏览器中，表单顶部约在 847px；用户必须先滚过完整权限对比表，表格还需要横向滚动才能查看全部角色。
- 建议：移动端先展示注册表单，将权限说明折叠或移到表单后；角色名称改为用户可理解的产品文案。

## 页面与功能切换专项

### UX-027 背题切换下一题不会回到顶部

- 状态：**已修复**
- 优先级：高
- 位置：`src/components/RecitePlayer.tsx:53`
- 现象：长题阅读到底部后点击“记住了”或“没记住”，下一题会保持上一题的滚动位置，可能直接显示题目中部或底部。
- 建议：题目索引变化时统一复位滚动位置；优先使用布局阶段或路由级滚动管理，避免绘制后再跳动。

### UX-028 公开页面间没有统一滚动复位

- 状态：**已修复**
- 优先级：高
- 位置：`src/layouts/AppShell.tsx:62`
- 现象：`window.scrollTo(0, 0)` 只存在于 AppShell。移动端从注册页底部进入登录页时，实测新页面仍停留在最大可滚动位置 `scrollY≈45.6`；首页、题库浏览和访客模式之间也可能继承旧滚动位置。
- 建议：在路由根部增加统一的滚动恢复策略；明确区分新页面回顶部与浏览器后退恢复原位置。

### UX-029 进入或退出沉浸模式时外壳瞬间消失/出现

- 状态：**已修复**
- 优先级：高
- 位置：`src/layouts/AppShell.tsx:82`
- 现象：进入刷题、背题或错题重刷后，AppShell 直接返回子页面，侧栏、移动底栏和页脚会瞬间卸载；退出时整套外壳又立即出现，造成明显布局跳变。
- 建议：为普通布局与沉浸布局增加统一的过渡边界，或保持外层尺寸稳定后再切换内容。

### UX-030 刷题数据从骨架屏切到真实内容缺少衔接

- 状态：**已修复**
- 优先级：高
- 位置：`src/pages/PracticePage.tsx:43`、`src/pages/RecitePage.tsx:44`、`src/pages/WrongPracticePage.tsx:49`、`src/pages/GuestPracticePage.tsx:256`
- 现象：加载骨架分支直接卸载，真实页面随后以初始透明状态挂载。慢设备上可能出现“骨架消失—背景短暂闪空—题面淡入”。
- 建议：用同一个带最小高度的状态容器承载 loading/error/content，并让骨架与真实内容真正交叉淡化。

### UX-031 ContentCrossfade 并非真正交叉淡化

- 状态：**已修复**
- 优先级：高
- 位置：`src/components/motion/ContentCrossfade.tsx:20`
- 现象：组件使用 `mode="wait"`，旧内容会先用约 100ms 完全退场，新内容再用约 200ms 入场；中间可能出现空容器和内容高度收缩。
- 建议：使用 `sync` 或 `popLayout`，并为容器保留稳定的最小高度；若必须顺序切换，应避免将其称为 crossfade。

### UX-032 题库 Tab 切换会连续播放两轮状态动画

### UX-033 首页分页重复执行骨架切换和卡片逐个入场

### UX-034 顶层页面切换固定增加顺序动画等待

- 建议：缩短或取消常规页面退场动画；优先让导航反馈立即更新，并限制同一时间的重复导航。

### UX-036 试题分页加载期间页码与内容不一致

- 建议：显示“正在加载第 N 页”，或在新数据成功后再提交页码；避免让旧数据冒充新页数据。

### UX-037 滚动复位在绘制后执行，可能先闪旧位置再跳顶部

- 状态：**待修复**

- 建议：将滚动管理提升到路由层，必要时使用布局阶段处理，并避免与浏览器原生后退位置恢复冲突。

### UX-038 动效组件在 render 阶段更新状态

- 状态：**待修复**
- 优先级：中
- 位置：`src/components/motion/QuestionTransition.tsx:34`、`src/components/import/ImportWizard.tsx:480`
- 现象：为计算切换方向，组件在 render 阶段调用 setState，每次索引或步骤变化都会触发额外渲染；快速翻题或连续切换导入步骤时可能出现轻微掉帧或方向状态不稳定。
- 建议：用 ref 记录上一次索引，或在事件触发时直接传递方向，避免 render-phase update。

### 专项验证中表现正常的部分

- 登录与注册之间的 SPA 跳转在浏览器采样中约 50ms 内完成 DOM 切换，没有出现长时间白屏。
- 题目切换已使用 `popLayout`，避免了 `mode="wait"` 带来的完整空窗。
