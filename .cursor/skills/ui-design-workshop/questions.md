# UI 设计工坊 — 分阶段题库

按当前阶段选用；已澄清的跳过，未澄清的可在本轮一并提出。

## 阶段 1：立项

- 你要设计的是哪个**页面或功能**？（例如：登录页、活动报名、设置页）
- **谁**是主要用户？使用场景是手机、桌面还是两者？
- 用户来这里要完成的**一件事**是什么？（注册、购买、提交表单…）
- 有没有**参考**（竞品、截图、品牌手册）或必须遵守的**设计规范**？
- 项目用的**技术栈/组件库**是什么？是否已有 design token 需要对齐？

## 阶段 2：视觉方向

- 用 3 个词描述你希望用户感受到的**情绪**（如：可信、活泼、克制）
- 更倾向**浅色还是深色**？有没有品牌色必须出现？
- 有没有**明确不要**的风格？（如：不要紫渐变、不要圆角卡片墙）
- 若提供两个方向，你更倾向 A 还是 B？或希望如何混搭？

## 阶段 3：设计系统

- 主色除了品牌色，还需要几种**强调/语义色**（成功、警告、错误）？
- 正文与标题：偏好**衬线/无衬线**？有无指定字体或「类似 xxx 网站」？
- 整体密度：**信息密集**还是**大量留白**？
- 动效：**克制**还是**入场有仪式感**？是否需要考虑减弱动效（无障碍）？

## 阶段 4：结构与线框

- 页面上**最重要的一块**应该占视觉焦点的哪里？
- 有哪些**必选区块**？（导航、Hero、表单、列表、页脚…）
- **移动端**是否需要与桌面完全不同的信息顺序？
- 是否需要在本方案里定义**空态、加载中、错误**？

## 阶段 5：组件规格

- 有哪些**关键组件**必须写清？（主按钮、表单、卡片、弹窗、导航…）
- 主按钮上的**文案**有偏好吗？
- 表单字段有哪些？**校验失败**如何提示？
- 是否需要**多语言**或特殊无障碍要求？

## 阶段 6：终稿

- 设计文档文件名有偏好吗？（默认 `docs/design/{页面名}.md`）
- 是否需要**英文摘要**或仅中文？
- 有没有必须写进「开发交接」的**里程碑或截止日期**？
